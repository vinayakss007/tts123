# DAaaS Platform - User Guide

## Getting Started

1. **Create an Account**: Register at the platform URL with your email
2. **Set Up Organization**: A personal workspace is created automatically
3. **Upload Data**: Go to Datasets and upload your first CSV, Excel, or JSON file

## Features

### Data Upload & Management
- Supported formats: CSV, Excel (XLSX/XLS), JSON, Parquet, TSV
- Maximum file size: 500 MB (varies by plan)
- Automatic column type detection and profiling
- Dataset versioning for tracking changes

### Data Cleaning
- Remove duplicates
- Fill missing values (mean, median, mode, or custom)
- Remove outliers (IQR or Z-score method)
- Normalize/standardize numeric columns
- All operations are reversible

### Analytics
- Descriptive statistics for all columns
- Correlation analysis with heatmap visualization
- Distribution analysis with normality testing
- Hypothesis testing (t-test, chi-square, ANOVA)

### Machine Learning
- AutoML: Automatically selects the best model
- Supported tasks: Classification, Regression, Clustering
- Training progress tracking in real-time
- Model versioning and comparison
- One-click predictions with deployed models

### AI-Powered Reports
- Automatic report generation from your data and analyses
- Customizable report templates
- Export to PDF, HTML, or Markdown
- AI generates insights, summaries, and recommendations

### Collaboration
- Invite team members to your organization
- Role-based access control
- Real-time notifications for completed tasks
